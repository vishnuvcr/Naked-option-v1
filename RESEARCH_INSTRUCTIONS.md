# Project Research Instructions

- Keep research finite and phase-based.
- Main README is the public status index and must stay synchronized.
- Every phase gets its own branch.
- Developer and tester environments remain isolated by role.
- Developer implements; tester independently audits.
- No phase may advance before tester report.
- Every error is logged with root cause and fix.
- Every result, including null/failure, is logged.
- Prefer official/free sources before paid sources.
- Cache data and reuse immutable snapshots rather than re-downloading blindly.
- Use Python/Rust and GitHub Actions.
- Include realistic Paytm Money transaction-cost assumptions after verifying historical applicability.
- End with a structured manuscript containing tables, figures, appendices and supplements.
