## P1 statistical/inference issues in the amended protocol

1. **The bootstrap null is not specified.** The protocol says to recompute maximum studentized improvements in moving-block resamples, but does not say the loss differentials are centered/recentered under the null. A block resample of raw differentials estimates the observed-effect distribution, not automatically the null distribution for a no-improvement test. Freeze an explicit null-centering algorithm and a one-sided test before execution.
2. **Class cardinality is unresolved.** The common direction labels are UP/DOWN/FLAT, but paper-native classifiers can be binary and price-forecast conversions may produce hard classes. Brier score for binary versus multiclass labels is not directly interchangeable without a fixed formulation. Either declare the confirmatory family on one common label schema and identical timestamps, or separate families by target schema; record per-class probability outputs and deterministic hard-label conversion.
3. **The family maximum and missing-cell handling are incomplete.** Specify whether every candidate statistic is computed on identical evaluation timestamps within a target/horizon, how max-statistic studentization works, the null-centered block draw, and how a planned candidate that fails or is not estimable affects the family. “Retain as NOT_ESTIMABLE” is good reporting but does not alone define the inferential denominator/family.
4. **Confidence intervals are underspecified.** Specify percentile/basic/studentized intervals, endpoint and multiplicity adjustment (if any); retain raw paired effect and the adjusted familywise result separately.
5. **Regression baselines need exact equations.** “Last-observation persistence” for next-open predictions is ambiguous. Define which prior OHLC field predicts next open, and use the same target scale and timestamps for paired loss differences.
6. **The primary common task and paper-native tasks are mixed in one broad manifest.** Freeze a per-row target schema, endpoint formula, model-output type and forecast-to-label conversion before PPR-3. Paper-native metrics whose target/split is underspecified must remain descriptive/blocked rather than entering the common confirmatory maximum.
