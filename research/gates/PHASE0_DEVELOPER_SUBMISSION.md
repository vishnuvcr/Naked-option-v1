# Phase 0 Developer Submission

## Scope

Establish the research contract before empirical work begins.

## Completed

- Canonical README created.
- Research plan and protocol created.
- Finite method registry created.
- Cost model and data-source registry created.
- Status/error/research/chat decision logs created.
- Developer/tester role separation encoded.
- CI protocol workflow added.
- Deterministic protocol validator added.

## Gate criteria

1. Required files exist.
2. Method registry IDs are unique.
3. Phase ledger is complete.
4. Research plan contains look-ahead, holdout, costs and tester controls.
5. Workflow is automatic on push/PR.

## Developer instruction to tester

Independently verify every criterion, inspect for contradictions and hidden leakage assumptions, and return PASS or REQUEST_CHANGES. Do not modify the developer branch while reviewing.
